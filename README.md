RAppleWin
========

Modified version of [AppleWin](https://github.com/AppleWin/AppleWin) supporting RetroAchievements.

Android port work is tracked in [ANDROID_PORTING_PLAN.md](ANDROID_PORTING_PLAN.md). The ARM64 libretro core build is available through GitHub Actions. A Java Android app shell and disk image picker are in `android/app-shell`; the shell does not yet run the core.
