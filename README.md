RAppleWin
========

Modified version of [AppleWin](https://github.com/AppleWin/AppleWin) supporting RetroAchievements.

Android port work is tracked in [ANDROID_PORTING_PLAN.md](ANDROID_PORTING_PLAN.md). The ARM64 libretro core and Android JNI host bridge build through GitHub Actions. A Java shell and disk image picker are in `android/app-shell`; APK packaging and activity integration for the native libraries are still in progress.
